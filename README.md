# تطبيق العجاج لفواتير الكهرباء

مشروع Android لإدارة المشتركين وفواتير الكهرباء والتحصيل، يعمل محليًا أولًا.

## البناء

يُبنى المشروع عبر GitHub Actions باستخدام Gradle وJDK 17. افتح تبويب Actions وشغّل سير العمل Build Android APK.

> الميزات المتقدمة مثل الطباعة عبر Bluetooth والنسخ السحابي تحتاج إلى استكمال واختبار قبل اعتماد التطبيق للإنتاج.
